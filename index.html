Prolog Interpreter & Visualizer

Go • TypeScript • Vite • Interpreters

An interactive Prolog interpreter and execution visualizer built with Go and TypeScript. Users can write Prolog facts, rules, and queries and inspect resolution step by step, including unification, substitutions, recursive rule evaluation, failures, and backtracking.

  • Implements parsing, unification, recursive resolution, DFS, backtracking, arithmetic, and built-ins
  • Visualizes goals, clause attempts, variable bindings, rule expansion, failures, and solutions
  • Supports trace stepping, scrubbing, auto-play, speed controls, and editable programs and queries
  • Includes Go unit/integration tests and Playwright browser end-to-end tests

Lisp Compiler

Go • Compilers • x86-64

A Lisp-to-x86-64 compiler written in Go with lexical analysis, parsing, AST construction, control flow, lexical scoping, short-circuit logic, and platform-specific code generation.
